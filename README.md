# Калькулятор неснижаемого остатка денежных средств

Один HTML-файл: `Калькулятор_неснижаемого_остатка.html`. Отвечает на вопрос собственника «сколько денег должно лежать на счёте» и показывает, на сколько дней компании хватит текущего остатка, если поступления остановятся.

## Что показывает

- **Запас в днях** — крупная цифра и цветной статус: красный — ниже минимума, жёлтый — минимум есть, но до комфорта не хватает, зелёный — в безопасной зоне.
- **Лента дней** — каждая клетка = 1 день. Закрашено столько дней, на сколько хватит остатка; пунктиром отмечены минимум и комфортный уровень.
- **Минимальный и комфортный остаток**, а также сколько не хватает (или сколько свободно).
- **Структура обязательных платежей** по пяти группам с долями.
- **Готовый текст для собственника** — кнопка «Скопировать текст».

## Как пользоваться

1. **Обязательные платежи в месяц.** Введите средние суммы за последние 3–6 месяцев, лучше из отчёта ДДС. Пустые строки считаются нулём. Своя статья добавляется кнопкой «+ Добавить свою статью».
   - Обычных поставщиков не включайте — их, как правило, можно перенести. Включайте только тех, без кого остановится работа.
   - Годовые и квартальные платежи (налог на имущество, страховки, НДС) пересчитайте на месяц.
2. **Риски и горизонт.** Отметьте факторы, которые относятся к компании. Горизонт посчитается сам; ползунком его можно задать вручную.
3. **Остаток и проверка.**
   - **Текущий остаток** — нужен для расчёта запаса в днях.
   - **Худший месячный ЧДП за год** — со знаком минус; необязательно. Если он больше минимума, комфортный уровень поднимается до этой суммы.
   - **Неиспользованный лимит кредитной линии** — необязательно.
4. Скопируйте текст для собственника и отправьте его в письме или мессенджере.

Кнопка «Вернуть пример» восстанавливает демо-данные.

## Как считается

| Показатель | Формула |
|---|---|
| Дневная сумма обязательных платежей | обязательные в месяц ÷ 30 |
| Горизонт (авто) | 14 дн. + надбавки за отмеченные риски, в пределах 7–90 дн. |
| **Минимум** | дневная сумма × горизонт |
| **Комфортный** | дневная сумма × (горизонт + 14), но не меньше худшего месячного дефицита ЧДП |
| Минимум собственными деньгами | max(минимум − лимит кредитной линии; минимум ÷ 2) |
| **Запас в днях** | текущий остаток ÷ дневная сумма |

Надбавки за факторы риска:

| Фактор | Дни |
|---|---|
| Один клиент даёт больше 30% поступлений | +14 |
| Отсрочка покупателям больше 30 дней | +7 |
| Нет кредитной линии или овердрафта | +7 |
| Выраженная сезонность выручки | +7 |
| Крупное погашение кредита в ближайшие 3 месяца или ковенанты банка | +7 |
| Госзаказчики, проектные оплаты по актам | +7 |
| Работаем по предоплате | −4 |
| Много мелких клиентов, оплаты каждый день | −4 |

Кредитная линия может заменить часть резерва, но не больше половины: банк вправе сократить лимит в любой момент.

**Ограничение.** Калькулятор задаёт политику остатков на месяц вперёд. Кассовые разрывы внутри месяца (например, налоги 28-го, а оплата клиента 30-го) он не видит — для этого нужен платёжный календарь по неделям.

## Настройка

Все параметры — в начале блока `<script>` в файле, менять можно в любом текстовом редакторе:

| Что | Где | Сейчас |
|---|---|---|
| Статьи платежей и демо-суммы | `MAND` — `[ключ, название, подсказка, сумма, номер группы]` | 21 статья |
| Группы платежей | `GROUPS` | 5 групп |
| Факторы риска и дни | `RISKS` — `[ключ, текст, дни]` | 8 факторов |
| Какие риски отмечены в примере | `DEFAULT_RISKS` | `["conc","noline"]` |
| Базовый горизонт | `BASE` | 14 дней |
| Запас для комфортного уровня | `EXTRA_DAYS` | 14 дней |
| Пример остатка, худшего месяца, лимита | `EXTRA` | 4 000 000 / −6 000 000 / 0 |

Пример: чтобы для клиента сразу открывался пустой калькулятор, обнулите четвёртое значение в каждой строке `MAND` и `EXTRA`.

## Размещение

- **Локально:** откройте файл двойным щелчком в любом современном браузере (Chrome, Edge, Firefox, Safari).
- **На сайте:** загрузите файл как отдельную страницу, например `irix2.ru/kalkulyator-ostatka.html`.
- **Клиенту:** отправьте файл в мессенджере или по почте.

Интернет нужен только для фирменных шрифтов (Google Fonts). Без него калькулятор работает с системным шрифтом.

**Конфиденциальность:** все расчёты выполняются в браузере. Введённые цифры никуда не отправляются и не сохраняются; после закрытия вкладки они исчезают.

## Проверка

Расчёты сверены с независимым расчётом в Python на 7 сценариях: демо-данные, данные реальной компании, ручной горизонт, низкорисковый профиль с ограничением горизонта 7 дн., добавление и удаление своих статей, сброс. Расхождений нет.
